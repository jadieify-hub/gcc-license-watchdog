# GCC License Watchdog

Windows-служба наблюдает за локальным Guardant Control Center (GCC) и восстанавливает его при характерной утечке лицензий.

## Когда происходит перезапуск

Для каждого локального сетевого компонента служба проверяет:

1. `remoteMode == 3`;
2. `flags.remote == false`;
3. `maxConcurrentResource > 0`;
4. `floatingResource == 0`;
5. среди сессий этого же ключа, продукта и компонента повторяется `user.id` или нормализованное видимое имя. При сравнении имён регистр и пробелы не учитываются, а меняющийся цифровой суффикс вида `(12345)` отбрасывается.

Полный ресурс с уникальными пользователями только журналируется. После успешного восстановления действует пятиминутная защита от повторного рестарта.

## Установка

Запустите `GCC-License-Watchdog-Setup.exe` от имени администратора. Установщик:

- размещает программу в `Program Files`;
- создаёт службу `GCC License Watchdog` от `LocalSystem`;
- включает автоматический отложенный запуск и восстановление службы при сбое;
- запускает службу сразу после установки.

Текущая сборка не подписана сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Для распространения клиентам установщик желательно подписать code-signing сертификатом.

## Удаление

Доступны три обычных способа:

- «Параметры → Приложения → GCC License Watchdog → Удалить»;
- «Панель управления → Программы и компоненты»;
- «Пуск → GCC License Watchdog → Удалить GCC License Watchdog».

Деинсталлятор останавливает и удаляет только службу наблюдателя. Guardant Control Center не изменяется. Перед завершением можно выбрать, удалить или сохранить журналы и настройки.

## Конфигурация и журналы

- конфигурация: `%ProgramData%\GCC License Watchdog\appsettings.json`;
- журналы: `%ProgramData%\GCC License Watchdog\logs`;
- критические ошибки дополнительно: Windows Event Log → Application.

После изменения конфигурации перезапустите `GCC License Watchdog` через `services.msc`.

## Проверка состояния

```powershell
Get-Service -Name 'Guardant Control Center','GCC License Watchdog'
Invoke-RestMethod 'http://localhost:3189/v1.0/lm/features'
```

## Сборка

```powershell
.\scripts\build.ps1
```

Скрипт локально устанавливает закреплённые инструменты в `.tools`, запускает тесты, публикует self-contained `win-x86` приложение и создаёт:

`artifacts\installer\GCC-License-Watchdog-Setup.exe`

## Ограничение детектора

Повтор пользователя — эксплуатационная эвристика. Редкое легитимное открытие нескольких сеансов одним пользователем может вызвать восстановление. Цифровая часть в конечных скобках считается идентификатором подключения; если она является значимой частью настоящего имени, возможна ложная группировка. Утечка, при которой все зависшие записи принадлежат разным пользователям, автоматически не распознаётся.
